MySQL, lesson 1

What is a database, and how does it work?

A database is where a website keeps its facts. By the end of this page you will know what a table, column, row and query are, and you will have run a few queries yourself.

1. The filing room idea

Picture a school office. Everything the school knows about its students lives in a filing room. SQL words are just names for the parts of that room.

Databasethe filing room
Tableone cabinet, e.g. students
Rowone folder, one student
Columnone blank on every form
Querya request to the clerk

A MySQL server can hold many databases. Each database holds tables. Each table holds rows. Each row is split into columns.

2. Anatomy of a table

This is a students table. Choose what you want to find, then click the table.

Click a column header such as fullname. A column holds one kind of information for every student.

Data types

Each column accepts only one kind of value. This keeps data tidy: you cannot put a name into an age column.

INT
whole numbers, e.g. id, age
VARCHAR(100)
text up to 100 characters, e.g. fullname
DATE
a calendar date, e.g. 2026-11-14
DECIMAL
exact numbers with decimals, e.g. prices

The primary key

Two students can share a name, so each row gets a unique id. This is the primary key. It never repeats, and AUTO_INCREMENT makes MySQL assign the next number for you.

3. How a website uses a database

Every time a page loads, the server asks the database for data and builds the HTML from the answer. Step through a visit to student.php?id=4.

Change the URL to id=2 and the same page shows Kenshi. One page design, any amount of data. That is why a shop with a million products does not need a million pages.

4. What is a query?

A query is an instruction written in SQL (Structured Query Language). Read this one like a sentence:

SELECT fullname, email  -- show me these columns
FROM students         -- from this table
WHERE id = 4;        -- only rows that match

The four things you will do most often, known as CRUD:

SELECT
read data (search, filter, view)
INSERT
add a new row (sign up, post, order)
UPDATE
change existing rows (edit profile)
DELETE
remove rows (cancel order)

6. Your first commands in the real CLI


Start MySQL in XAMPP, click Shell, then type these one at a time. Each ends with ;


mysql -u root              # log in (no password by default)
SELECT VERSION();            -- which server am I talking to?
SHOW DATABASES;             -- list all filing rooms
CREATE DATABASE school;    -- make a new one
USE school;                 -- step inside it
CREATE TABLE students (
  id INT AUTO_INCREMENT PRIMARY KEY,
  fullname VARCHAR(100) NOT NULL,
  email VARCHAR(100),
  phonenumber VARCHAR(20)
);
INSERT INTO students (fullname, email, phonenumber)
VALUES ('Rose', 'rose@gmail.com', '0811111111');
SELECT * FROM students;
exit


If the prompt changes to ->, MySQL is waiting for more. You forgot the ;. Type it and press Enter.



Quick review



  
Database: a container for related tables.

  
Table: a grid about one kind of thing.

  
Column: one attribute, the same for every row.

  
Row: one complete record.

  
Primary key: the unique id of each row.

  
Query: an SQL instruction to read or change data.
